MAVIS Desktop for Ubuntu / Zorin OS (Debian .deb build)

For distributors:
  python3 packaging/deb.py dist/mavis.deb

For users:
  1. Download mavis.deb and open it in your graphical package installer.
  2. Click Install and approve the system's normal installation prompt.
  3. MAVIS's installer automatically provisions FFmpeg, Python, the local
     Ollama service and qwen3:4b model, and the Qwen voice engine and its
     checksum-verified models. Internet and several GB of free disk space
     are necessary for this one-time installation.
  4. Launch MAVIS from the Applications menu. The first launch automatically
     creates an isolated Python environment and installs its Python libraries.
     MAVIS then opens its browser-based local studio.

No terminal commands or separate AI/model installs are required of end users.
There is no subscription or billing requirement in this temporary build.
The original billing code is retained in Git history for later reinstatement.

YouTube publishing still requires the user's own Google/YouTube authorization
and channel configuration. Channel-specific media and animation assets must be
provided by the user. No installer can create their Google credentials, channel,
voice instructions or copyrighted channel assets.

The installer runs third-party network downloads at installation time; it fails
clearly rather than claiming a working install when provisioning is incomplete.
A failed download can be retried by rerunning the package installation. Check
the package-manager logs for error details. The machine must run systemd.
